# XrayR - Community Fork

> 原始仓库 (XrayR-project/XrayR-release) 已删除。
> 此仓库是从运行中的服务器备份的运行时文件。

## 内容说明

- `XrayR` - 主程序二进制文件 (需手动下载或从 Releases 获取)
- `config/` - 配置文件 (已脱敏处理，需修改后使用)
- `system/` - systemd 服务文件
- `scripts/` - 管理脚本
- `install.sh` - 安装引导脚本

## 安装

1. 从 Releases 下载 XrayR 二进制文件
2. 运行 `sudo bash install.sh`
3. 编辑 `config/config.yml` 填写你的面板信息
4. 将 XrayR 和配置文件复制到对应目录
